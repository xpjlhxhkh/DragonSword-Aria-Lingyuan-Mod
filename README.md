# 龙之剑：觉醒 — Aria 替换「泠鸢」mod

把《龙之剑：觉醒》中可操作角色 **阿莉娅（Aria）** 的模型替换成 **泠鸢**（MMD 模型），
提供两种外观：**公式服 3.0（栗子发）** 与 **素体**。
v1.1 起，游戏内的 **头像 / 立绘 / 图标（19 个 UI 资源）** 也换成了同款 2D 立绘。

> 本仓库只放说明；pak 文件在 **Releases** 里下载。
> 如果想要**自己改过贴图**的版本（皮肤/服装细节微调），看这个仓库：
> [DragonSword-Aria-Lingyuan-CustomTex](https://github.com/xpjlhxhkh/DragonSword-Aria-Lingyuan-CustomTex)

## v1.2 更新内容

1. **手指能分开动了**：权重改成"每根手指只跟自己的指骨"（硬分指），
   离线测试单弯一指时，其余四指顶点位移 **0.00cm**（旧版权重会掺 15~20% 邻指权重，五根手指像粘在一起）。
2. **袖子/上背修好**：`服纱-袖` 改成**法线投射绑定** —— 每个布料顶点沿法线反方向打到身体上，
   按命中点的重心坐标抄身体权重。抬臂、扭身时袖子不再被撕开、上背不再露出来。
3. **去内裙 + 去裤**（按需求删掉内衬与安全裤），保留后背纱带。
4. **UI 立绘改成"取原图左侧 66%"**：原来居中裁切，游戏里会被左右裁掉，现在按游戏实际显示区域裁。
5. 贴图回到**原始图集**（不含手改贴图，手改版见上面的 CustomTex 仓库）。

## 安装

1. 打开游戏目录：`<Steam>\steamapps\common\DragonSword  Awakening\DS\Content\Paks\`
2. 如果没有 `~mods` 文件夹，**手动新建一个**（名字必须是 `~mods`）
3. 把**其中一个** pak 复制进 `~mods\`
4. 重启游戏

> ⚠️ 同一时间只能装一个版本（它们替换同一套资产）。
> 与其他替换 Aria 的 mod 冲突，请先移除其它替换包。

## 已知限制

- **手指是"整片按指骨弯"**：模型四根手指根部是连成一片的（指缝约 0.2cm），
  做不到逐指完全独立；弯曲角度大时指缝处会有轻微拉伸。
- 没有布料/头发物理（游戏自带物理不会驱动替换网格）。
- 公式服裙摆前方原有的三块装饰面板（`裙-金属`）已移除：贴图合并成图集后分辨率过低，会显示成低像素花纹。
- epic / rare 换装的外观没有替换，仍是游戏原模型。
